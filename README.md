# FIUI Paper 1 — Reproducibility Repository

**Paper:** *Design, Development, and Validation of a Financial Information Usefulness Index: Evidence from Tehran Stock Exchange-Listed Firms*

Authors: **Mojtaba Fakourrad** and **Yaghoub Pour Karim**

This repository contains the Python code, processed firm-year data, de-identified expert-validation data, exact reported-result snapshots, and raw source-data archives used for the revised first FIUI paper.

## What is reproduced

The public analysis pipeline reproduces the main empirical results in the revised manuscript:

- 319 Tehran Stock Exchange firms, 2013–2022 / 1392–1401;
- 2,940 available firm-year records;
- 2,370 FIUI-eligible firm-years;
- nine original empirical component scores;
- revised eight-component primary FIUI after removing duplicated neutrality;
- Entropy, CRITIC, Equal, and PCA weights;
- primary Entropy–CRITIC consensus weights;
- complete-case robustness;
- financial vs. non-financial robustness;
- descriptive and year-level FIUI statistics;
- component Spearman correlation matrix;
- expert CVR/CVI results and 36-item Cronbach alpha;
- current- and next-year nomological tests;
- Round-2 reviewer diagnostics and frozen paper-exact result tables.

## Primary revised FIUI

The revised primary specification contains eight empirical dimensions:

1. Predictive value
2. Confirmatory value
3. Faithful representation
4. Structured-data completeness
5. Extraction confidence
6. Accounting-return mapping stability
7. Timeliness
8. Conservatism

Neutrality is excluded from the primary specification because its empirical proxy was identical to faithful representation.

The paper-reported primary weight vector is the normalized mean of Entropy and CRITIC weights. The exact reported values are preserved in `reported_results/round1/revised_weights_8.csv` and independently regenerated by `src/02_primary_fiui.py`.

## Important reproducibility note

The repository intentionally distinguishes between:

- **recomputed outputs**, generated by the scripts from the included processed data; and
- **frozen reported-result snapshots**, which preserve the exact numerical tables used in the manuscript and referee responses.

The paper's final analysis snapshot contains a locked fallback value for the last-year predictive component because no next-year growth observation exists for fiscal year 1401. This constant is declared explicitly in `src/common.py` so that the published weight vector and year-level statistics are exactly reproducible rather than silently changed by a new software run.

`src/99_validate_reported_results.py` checks the regenerated key results against the frozen manuscript snapshots.

## Raw data and GitHub

The full package includes large CODAL and TSETMC archives in `data/raw_archives/`. The repository's `.gitattributes` is configured to track these ZIP files using **Git LFS**. If you do not want to use Git LFS, publish the core repository without `data/raw_archives/` and place the raw archives in a release or external research-data repository.

## Expert data and privacy

The public survey datasets are de-identified:

- timestamps were removed from the 36-item questionnaire;
- free-text comments were not included;
- direct CVR/CVI records use expert codes rather than names.

## Interpretation

The repository reproduces the paper's deliberately limited claim: the FIUI is internally reproducible and robust as a comparative research measure, while full content validity and external/criterion validity are not claimed.
